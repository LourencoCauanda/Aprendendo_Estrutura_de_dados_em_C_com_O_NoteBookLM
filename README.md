A proposta é criar um caderno temático que organize conteúdos, fontes e experimentos, documentando também o processo de aprendizagem e interação com IA.

## 📓 Miniguia de Estudo
1. Fundamentos da Linguagem C

    Objetivo e Escopo: O foco principal é construir uma base sólida em programação, abrangendo desde conceitos fundamentais até a implementação prática de estruturas de dados e algoritmos eficientes.
   
    Elementos Léxicos: O código C é composto por tokens, que incluem identificadores (nomes de variáveis e funções), palavras-chave reservadas (como int, return), constantes, operadores e separadores.
   
    Estrutura de um Programa: Um programa básico em C inicia com diretivas de pré-processador (como #include <stdio.h>) e a execução começa obrigatoriamente pela função main().
   
    Tipos de Dados Primitivos: As fontes descrevem tipos básicos como char (caracteres), int (inteiros), float e double (pontos flutuantes) e void (sem valor).

3. Lógica de Programação e Controle de Fluxo

    Operadores: A linguagem oferece uma vasta gama de operadores, incluindo aritméticos (adição, subtração, multiplicação, divisão e módulo), relacionais (para comparações como == ou >) e lógicos (&&, ||, !).
   
    Instruções de Controlo Condicional: O fluxo do programa pode ser alterado usando if-else para decisões baseadas em condições lógicas ou switch para seleções múltiplas baseadas em constantes.
   
    Laços de Repetição (Loops): Para executar tarefas repetidamente, utilizam-se os laços for (com inicialização, condição e atualização integradas), while (com teste no início) e do-while (que garante pelo menos uma execução antes do teste).

5. Modularização e Gestão de Memória

    Funções: São blocos de código projetados para realizar tarefas específicas, promovendo a reutilização do código. Elas podem receber argumentos e retornar um valor.
   
    Recursão: É o processo em que uma função chama a si mesma para resolver problemas que podem ser divididos em subproblemas menores, como o cálculo de fatoriais ou sequências de Fibonacci.
   
    Ponteiros: São variáveis especiais que armazenam o endereço de memória de outra variável, permitindo a manipulação direta da memória e a passagem de argumentos por referência.

7. Estruturas de Dados

    Arrays (Matrizes): Coleções de elementos do mesmo tipo de dado armazenados em locais de memória contíguos, permitindo o acesso via índices.
   
    Strings: Em C, as strings são tratadas como arrays de caracteres terminados por um caractere nulo (\0).
   
    Estruturas (Structs) e Uniões (Unions): Tipos definidos pelo utilizador que permitem agrupar variáveis de diferentes tipos de dados sob um único nome.

9. Tópicos Avançados

    Alocação Dinâmica de Memória: Permite ao programa solicitar memória durante a execução (run-time) utilizando funções como malloc(), calloc(), realloc() e libertá-la com free().
   
    Entrada/Saída de Ficheiros (File I/O): Capacidade de ler e escrever dados em dispositivos de armazenamento permanente, utilizando ponteiros de ficheiro e funções como fopen(), fclose(), fprintf() e fscanf().
   
    Estruturas Dinâmicas: O estudo aprofundado inclui a implementação de listas ligadas, pilhas, filas, árvores e grafos, essenciais para o desenvolvimento de soluções complexas.
